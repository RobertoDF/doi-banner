Support

Get help or report a problem

  • Open an issue: github.com/RobertoDF/doi-banner/issues. Include the DOI or link you used, your app (PowerPoint for Windows, Mac or the web, or a browser) and what you saw. A free GitHub account is needed to post.
  • Contact the maintainer: Roberto De Filippo, github.com/RobertoDF.
  • Existing answers: search open and closed issues and the README.

Using the PowerPoint add-in

  1. Click Home → DOI Banner to open the task pane.
  2. Paste a DOI (for example 10.1038/s41592-024-02318-2) or a web link, then click Fetch. Put several on separate lines to stack them into one image.
  3. Adjust the shape, text colour, typeface, accent or QR options, or open Edit text to change any field.
  4. Select a slide, then click Insert into slide. The banner is inserted as a vector image (SVG) where PowerPoint supports it, or as a transparent PNG otherwise.

Common problems

  • “DOI not found” — check the DOI. Some publishers register only with DataCite or not at all. You can still type the details yourself under Edit text.
  • Insert does nothing, or reports an error — click inside a slide in Normal view, not the slide sorter or outline, and try again.
  • The button says to open the page inside PowerPoint — the page is open in a normal browser. Use Download PNG / SVG or Copy image there.
  • Text colour — choose Near-black for light slides and White for dark ones. The Transparent background keeps the slide visible behind the banner.
  • Keynote — Keynote has no add-in API. Use Copy image on the website and the helper script described in the README.
